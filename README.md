# E-Commerce Web App

A full-stack e-commerce web application built using the MERN stack.
This project allows users to browse products, add items to cart, and interact with a responsive shopping interface.

## Features

* Product listing display
* Add to cart functionality
* Responsive user interface
* React frontend
* Node.js and Express backend
* REST API integration

## Technologies Used

### Frontend

* React.js
* CSS
* JavaScript

### Backend

* Node.js
* Express.js

## Project Structure

task-3-ecommerce-app

## Installation

### Clone repository

```bash
git clone https://github.com/Nayana9482/task-3-ecommerce-app.git
```

### Install dependencies

Frontend:

```bash
cd client
npm install
npm start
```

Backend:

```bash
cd server
npm install
node server.js
```
